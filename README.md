# WL Draft · ระบบร่างหนังสือราชการ

ส่วนหนึ่งของชุดแอป WL โรงเรียนบ้านวังลึก(ยุวนาฏชนูทิศ) ใช้ฐานข้อมูลและบัญชีผู้ใช้เดียวกับ WL Admin

## ที่ใช้งานได้
- **บันทึกข้อความ**, **หนังสือภายนอก**, **คำสั่ง** และ **ประกาศ** ตามแบบหนังสือราชการ (TH SarabunPSK 16 pt, A4, ขอบ บน 1.5 ซ้าย 3 ขวา 2 ล่าง 2 ซม.)
- แบบเนื้อหาสำเร็จรูป กรอกสั้นๆ แล้วกด "เติมเนื้อหาจากแบบ"
  - บันทึกข้อความ: ขออนุญาต, ขออนุมัติดำเนินโครงการ (แปลงจำนวนเงินเป็นตัวอักษรให้), รายงานผล, เขียนเอง
  - หนังสือภายนอก: ขอความอนุเคราะห์, เชิญประชุม/ร่วมงาน, รายงาน/ตอบหนังสือที่อ้างถึง, ส่งเอกสาร, เขียนเอง
  - คำสั่ง: แต่งตั้งคณะกรรมการดำเนินงาน (เลือกรายชื่อจากบุคลากรหรือพิมพ์เอง จัดเลขข้อ/ตารางรายชื่อ/มีหน้าที่ให้) · ช่อง "อาศัยอำนาจ" ตั้งต้นจากคำสั่งเดิมของโรงเรียน **ต้องตรวจทุกครั้ง**
  - ประกาศ: ประกาศทั่วไป, ประกาศหยุดเรียน/ปิดทำการ, เขียนเอง (บรรทัดที่ขึ้นต้น ๑. จัดเป็นรายการข้อ)
- แก้ทุกช่องได้ก่อนออกไฟล์ ดูตัวอย่างหน้า A4 ทันที
- ดาวน์โหลด Word (.docx) และพิมพ์/บันทึกเป็น PDF จากเบราว์เซอร์
- เลือกผู้ลงนามจากรายชื่อบุคลากร (ตั้งต้นจากคำสั่งที่ ๒๓/๒๕๖๙) · ใช้เลขไทยทั้งฉบับได้
- บันทึกประวัติ เปิดแก้ ทำสำเนา และลบได้

- ปุ่ม **ให้ AI ร่าง** (Gemini Flash-Lite) ร่างเรื่องและเนื้อหาจากใจความสั้นๆ — ต้องติดตั้งฟังก์ชันตามหัวข้อด้านล่างก่อน

ยังไม่มี: ตารางในประกาศ

## ตั้งค่าครั้งแรก (ทำครั้งเดียว)
1. **สร้างตาราง:** Supabase โครงการเดียวกับ WL Admin → SQL Editor → วางทั้งไฟล์ `supabase/wl-draft.sql` → Run
   (ไม่แก้ตารางเดิม รันซ้ำได้) ก่อนรัน แอปจะเก็บข้อมูลไว้ในเครื่องนั้นเท่านั้น และแสดงแถบเตือน
2. **เปิดเว็บ:** repo นี้ → Settings → Pages → Deploy from a branch → `main` / `(root)` → Save

## ติดตั้งปุ่ม AI (ทำครั้งเดียว ใช้ฟรี)
1. ขอ API key ที่ aistudio.google.com → Get API key → Create API key (ไม่ต้องผูกบัตร) · **ห้ามใส่ key ในไฟล์หรือแชต**
2. Supabase → Edge Functions → **Secrets** → Add → ชื่อ `GEMINI_API_KEY` ค่า = key ที่ได้
3. Supabase → Edge Functions → **Deploy a new function** → Via Editor → ตั้งชื่อ `draft-ai` → วางโค้ดจาก `supabase/functions/draft-ai/index.ts` ทั้งไฟล์ → Deploy
4. (ไม่บังคับ) เปลี่ยนรุ่นได้โดยเพิ่ม Secret `GEMINI_MODEL` (ค่าตั้งต้น `gemini-3.5-flash-lite`)

ฟังก์ชันตรวจว่าล็อกอินและเป็นครู/แอดมินที่อนุมัติแล้วเท่านั้น และส่งไปยัง Gemini เฉพาะใจความที่พิมพ์ในช่อง AI (ระดับฟรีของ Google อาจนำข้อความไปปรับปรุงผลิตภัณฑ์ จึงห้ามใส่ชื่อนักเรียนหรือข้อมูลส่วนบุคคล)

## สิทธิ์
- ครูที่อนุมัติแล้วใน WL Admin: ร่าง บันทึก และแก้/ลบเอกสารของตัวเอง
- แอดมิน: แก้รายชื่อบุคลากร ตั้งค่าหัวหนังสือ และแก้/ลบเอกสารทุกฉบับ

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `js/app.js` | หน้าจอ |
| `js/templates.js` | แบบเนื้อหาสำเร็จรูป (เพิ่ม/แก้ถ้อยคำที่นี่) |
| `js/layout.js` | จัดหน้าเอกสาร ใช้ร่วมกันทั้งหน้าตัวอย่างและไฟล์ Word |
| `js/render.js`, `js/docx.js` | วาดหน้า A4 / สร้างไฟล์ .docx |
| `js/thai.js` | เลขไทย วันที่ไทย จำนวนเงินเป็นตัวอักษร |
| `js/db.js`, `js/config.js` | เชื่อม Supabase / เก็บในเครื่อง |
| `supabase/wl-draft.sql` | ตารางและสิทธิ์ |
| `supabase/functions/draft-ai/index.ts` | ฟังก์ชันเรียก Gemini (เก็บ key ฝั่งเซิร์ฟเวอร์) |
| `fonts/` | TH SarabunPSK (สัญญาอนุญาต DIP & SIPA ใช้และแจกจ่ายได้ฟรี) |
